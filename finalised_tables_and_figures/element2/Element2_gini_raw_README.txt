
Element 2 — ecological representativeness and distribution among MPAs

Element2_gini_raw.jpeg

This bubble plot shows the raw Gini coefficient describing how unevenly protected area extent and protected habitat are distributed among individual MPAs within each Western Indian Ocean sovereign state.

Rows represent sovereign states and columns represent five indicators: total MPA area, mangroves, coral reefs, seagrass and seamounts. The number printed within each bubble is the raw Gini coefficient for that country-indicator combination, and bubble colour represents the same value on a scale from 0 to 1. Values closer to 0 indicate a more even distribution among MPAs, whereas values closer to 1 indicate that the total area or protected habitat is concentrated in a relatively small number of MPAs. Bubble size is proportional to the total number of MPAs in the sovereign state.

Because the raw Gini coefficient is affected by the number of observations, values for countries with relatively few MPAs should be interpreted with caution.
